# Overview
**Goal:** Expand my portfolio by building a plugin that replaces EssentialsX

# What it does
TrueEssentials aims to replace the classic [EssentialsX](https://modrinth.com/plugin/essentialsx) plugin with a better alternative by stripping the bloat that comes with it while keeping it functional. The plugin gives more customization options then EssentialsX via a YAML configuration file, and has a few new features here and there, which can be enabled or disabled.

# What I learnt
- How to use annotation-based listeners
- How to use Async schedulers and async events
