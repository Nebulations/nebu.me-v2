# Overview
**Goal**: Learn what it takes to ship something people would want to purchase & expand my portfolio.

# What it does
Sapphire lets moderators punish players through menus instead of typing commands, and it handles the tedious parts, like picking a duration. Server owners define their own punishments in `punishments.yml` and choose what happens at each strike, so repeat offenders get escalated automatically. This plugin was heavily inspired by Minehut's moderation tools.
<br><br>
- **Punishments**: customizable reasons and durations, automatic escalation by offense count, and custom ban, mute and warning screens
- **Reports**: players can report others, and staff claim, view and edit reports with commands
- **Discord integration**: embeds are posted automatically when a punishment or report is issued
- **Chat filter**: regex-based, and it can issue a punishment automatically when triggered
- **Storage**: MySQL for networks, SQLite for single servers
- **Staff tools**: staff chat, clear chat, inventory viewing, vanish, and per-feature permission nodes
